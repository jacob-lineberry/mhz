# Security Policy

## Supported versions

Only the latest release and `main` receive security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately with [GitHub's private vulnerability reporting](https://github.com/jacob-lineberry/mhz/security/advisories/new). Do not open a public issue, discussion or pull request, and keep the details confidential until a fix is released. Please include the affected version, steps to reproduce and the impact.

## What to expect

This is a one-person open source project, so responses are best-effort: an acknowledgement within 14 days and a fix or a plan within 90 days. Fixes ship in a normal release with a GitHub security advisory (and a CVE where it applies), and you'll be credited unless you prefer not to be.

## Scope

Problems in third-party software this project depends on belong with its maintainers. If a dependency issue is already public, a public issue or pull request here is fine. If you used AI tools to find or write a report, please confirm the issue reproduces before sending it.
